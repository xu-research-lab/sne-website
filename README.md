# SNEs website

Source code of <https://sne.xulab.science>, the website for social niche
embeddings (SNEs) of the human gut microbiome.

- [How it works](#how-it-works)
- [Everyday maintenance](#everyday-maintenance) — change the site, update the server
- [Deploy to a new server](#deploy-to-a-new-server)

---

## How it works

- The website is a set of files: pages, styles, scripts and data. **nginx**
  sends them to the visitor.
- The dysbiosis model runs **in the visitor's browser**, not on the server.
- The only program running on the server is a small service behind `/map`. It
  matches uploaded 16S sequences to reference OTUs with vsearch, and it runs in
  **Docker**.

```
visitor ──► nginx ──┬──► website files     /srv/microbial/site/
                    └──► /map ──► Docker ──► vsearch
```

### What is in this repository

| Folder | What it is | Copied to, on the server |
|---|---|---|
| `web/` | pages, styles, scripts | `/srv/microbial/site/` |
| `data/web/` | data files the pages load | `/srv/microbial/site/data/` |
| `data/server/` | reference sequences for `/map` | `/srv/microbial/data/` |
| `server/` | the `/map` service | `/srv/microbial/server/` |
| `deploy/` | nginx and Docker settings, `update.sh` | `/srv/microbial/deploy/` |
| `script/` | scripts that build `data/web/` | not deployed |
| `tests/` | checks for the browser code | not deployed |

You never copy these by hand: `deploy/update.sh` does it.

## Everyday maintenance

### Change the website

1. Edit the files under `web/` on your computer.

2. **If you edited a CSS or JavaScript file** in `web/assets/`, raise its
   version number where it is loaded. Otherwise visitors keep the old file.

   ```bash
   grep -rn "card.js?v=" web/          # find where card.js is loaded
   # then change, for example, card.js?v=10 to card.js?v=11
   ```

3. Run the tests, then commit and push.

   ```bash
   cd tests/js && npm install && npm test && cd ../..
   git add -A && git commit -m "Describe what you changed" && git push
   ```

4. Update the server.

   ```bash
   ssh you@your-server
   cd ~/sne-website && bash deploy/update.sh
   ```

5. Open the site and press **Ctrl+Shift+R** (**Cmd+Shift+R** on a Mac).

### Change the data

The files in `data/web/` are generated by the scripts in `script/web_export/`.
Regenerate them only when the model, the embeddings, the traits or the taxonomy
change. This runs on the lab machine that holds the training data and the model
checkpoints (the checkpoints are not in git). The steps, in order, are in
[`script/web_export/README.md`](script/web_export/README.md).

Afterwards, commit, push and run `deploy/update.sh` as above.

### Check that the site is healthy

```bash
curl -s https://sne.xulab.science/health
```

Both `database_present` and `atlas_database_present` should be `true`. Then
open the site, search the atlas, click a point on the map, and run one
dysbiosis example.

### HTTPS certificate

It renews itself. To confirm renewal works: `sudo certbot renew --dry-run`.

## Deploy to a new server

You need an Ubuntu 22.04 or 24.04 server, a domain whose DNS A record points at
it, and ports **80 and 443** open. On Alibaba Cloud, open them in the
**security group** in the web console as well. Below, replace
`sne.xulab.science` with your domain.

### 1. Install the software

```bash
sudo apt update
sudo apt install -y git rsync nginx docker.io docker-compose-v2 npm \
                    certbot python3-certbot-nginx
```

### 2. Get the code and put it in place

```bash
git clone https://github.com/xu-research-lab/sne-website.git ~/sne-website
cd ~/sne-website
bash script/fetch_vendor.sh      # downloads the WebAssembly files git does not hold
bash deploy/update.sh            # copies everything to /srv/microbial/
```

### 3. Start the `/map` service

```bash
cd /srv/microbial
sudo docker compose -f deploy/docker-compose.yml up -d --build
curl -s localhost:8000/health    # both databases must be true
```

### 4. Set up nginx

```bash
# The /map rate limit: 10 requests per minute per visitor.
echo 'limit_req_zone $binary_remote_addr zone=map_limit:10m rate=10r/m;' \
  | sudo tee /etc/nginx/conf.d/map-limit.conf

sudo cp /srv/microbial/deploy/nginx-http.conf /etc/nginx/sites-available/sne
sudo sed -i 's/server_name _;/server_name sne.xulab.science;/' /etc/nginx/sites-available/sne
sudo ln -sf /etc/nginx/sites-available/sne /etc/nginx/sites-enabled/sne
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t && sudo systemctl reload nginx
```

The site now works at `http://sne.xulab.science`.

### 5. Turn on HTTPS

```bash
sudo certbot --nginx -d sne.xulab.science --redirect --agree-tos -m you@example.org
```

certbot gets a free certificate, switches the site to `https://`, sends
`http://` visitors there, and renews the certificate automatically.

### 6. Check it

Run the checks in [Check that the site is healthy](#check-that-the-site-is-healthy).

## When something goes wrong

| What you see | What to do |
|---|---|
| A change does not appear on the site | Raise the file's `?v=` number (step 2 above), then Ctrl+Shift+R |
| `update.sh` stops with `MISSING … .wasm` | Run `bash script/fetch_vendor.sh`, then `update.sh` again |
| Dysbiosis page: "no available backend found" | Same as above: a `.wasm` file is missing on the server |
| Sequence search or upload fails, `/health` says `false` | `cd /srv/microbial && sudo docker compose -f deploy/docker-compose.yml up -d --build` |
| Sequence search says "Too many requests" or "returned an error (429)" | The rate limit, 10 per minute per visitor; wait a minute |
| nginx will not reload | `sudo nginx -t` names the broken line |
| HTTPS stopped working | `sudo certbot renew`, and check that port 80 is still open |

Logs: `sudo docker logs microbial-map` for `/map`,
`sudo tail -f /var/log/nginx/error.log` for nginx.

## Run it on your computer

```bash
ln -sfn ../data/web web/data             # lets the pages find their data
cd web && python3 -m http.server 8080    # then open http://localhost:8080
```

Everything works except sequence search, which needs the `/map` service.

## Good to know

- **The dysbiosis model knows 8,850 OTUs; the atlas shows 14,093.** The model
  uses embeddings retrained without the disease studies, which cover fewer
  OTUs.
- **The model online is older than the paper's disease cohort.** It was
  trained on 13 diseases (10,276 samples, including autism spectrum disorder);
  the paper and the download page use the revised cohort of 12 diseases
  (10,358 samples). When the new checkpoints are ready, rebuild the model with
  `script/web_export/export_dysbiosis.py` and remove the notes about this on
  the dysbiosis and download pages.
- **The AUC to quote is 0.64** (leave-one-disease-out). `metrics.json` also
  holds 0.7976, measured on the model's own training cohort: never quote it.
- **Trait values come from three places.** BacDive: measured. Traitar:
  inferred from a genome. Everything else: predicted from the embedding.
